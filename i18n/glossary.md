# Glossário de tradução — Navegador COP31

Shared terminology for all target languages. Source language is Brazilian Portuguese. Translators (human or agent) must use these renderings consistently. Where a term is normally left in English in UNFCCC usage, keep it in English and add the local rendering in parentheses on first use only if the source does.

## Rules that apply to every language

- Translate the *meaning*, in the register of a serious briefing for negotiators and journalists. No marketing tone.
- Keep HTML tags, attributes, URLs and `{placeholders}` exactly as in the source. Translate only the human-readable text between tags.
- Keep acronyms as in the source (COP31, UNFCCC, NDC, GST, GGA, NCQG, MWP, JTWP, TAFF, LMDC, AOSIS, LDC, AGN, AILAC, BASIC, LMDCs, IPCC, AR7, UNEP, IEA, IISD, ENB, E3G, WRI, IDDRI, CAN, WWF).
- Proper names of institutions, publications and people stay as in the source (E3G, Carbon Brief, Germanwatch, Climate Analytics, Murat Kurum, Chris Bowen, Simon Stiell, André Corrêa do Lago). Transliterate names into Russian, Chinese and Arabic only when there is an established form (e.g. heads of state); otherwise keep the Latin spelling.
- Country, group and bloc names: translate into the target language using the UN's standard form (e.g. "Türkiye" is the official UN name; use the target language's UN form). Negotiating groups: use the established local form if one exists (e.g. "Grupo Africano" → "African Group", "Groupe africain", "Африканская группа", "非洲集团", "المجموعة الأفريقية").
- Numbers, dates and units: adapt format to the language (decimal separators, date order), keep values. "1,5 °C" → "1.5 °C" in English/Chinese, "1,5 °C" in Spanish/French/Russian, "1.5 درجة مئوية" in Arabic.
- Short UI strings (buttons, filter labels, column headers) must stay short.
- Strings that are arrays (months, position labels) must stay arrays of the same length and order.
- Do not add explanations, notes or alternatives. Output only the translated JSON.

## Position-table data strings (`d:` keys)

These are the English party/bloc names, topic names and position wordings from the positions tracker. They are in English in the source. For `en` copy them unchanged. For the other languages translate them tersely (they are table cells); keep bloc acronyms (AGN, AOSIS, LMDC, LDC, AILAC, EIG, EU, BASIC) unchanged and translate country names into the UN form in the target language.
